# Easy Magic for Horizon

Enchanting tables keep their items and can re-roll.

A port of [Easy Magic](https://github.com/Fuzss/easymagic) 8.0.1 by Fuzs to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MPL-2.0, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod. Its code uses Horizon's mod API and engine mixins (listed in `horizon-mod.toml`). Release [`easymagic-v0.4.1`](https://github.com/lavoide/horizon-ports/releases/tag/easymagic-v0.4.1) holds `easymagic.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
