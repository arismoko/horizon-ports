# Wearable lanterns for Horizon

Wearable lanterns for the trinket lantern slot.

A port of [Wearable lanterns](https://github.com/AbsentAbigail/WearableLantern) 1.0.1 by tsuki, Absent Abigail to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

This folder is the package source: a content mod (`horizon-mod.toml`, `assets/`, `data/`). Release [`trinketlantern-v1.0.1-horizon.2`](https://github.com/lavoide/horizon-ports/releases/tag/trinketlantern-v1.0.1-horizon.2) holds `trinketlantern.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
