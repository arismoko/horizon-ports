# Wearable lanterns

Wearable lanterns for the trinket lantern slot.

A port of [Wearable lanterns](https://github.com/AbsentAbigail/WearableLantern) by tsuki, Absent Abigail, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

It has not been ported to Sunrise yet. Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
