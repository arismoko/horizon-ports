# Accelerated Decay

Leaves decay quickly after a tree is cut.

A port of [Accelerated Decay](https://github.com/errormikey/accelerated-decay) by ErrorMikey, under the original's licence (GPL-3.0-only, in `LICENSE`; see `NOTICE`).

It has not been ported to Sunrise yet. Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
