# Ocean's Delight for Horizon

Squid, guardian and pufferfish dishes for Farmer's Delight, and the guardian soup feast (needs Farmer's Delight 0.5 or later).

A port of [Ocean's Delight](https://github.com/Scouter456/Oceans_Delight) fdrf-fabric-1.0.2-1.20 by Scouter to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

This folder is the package: a content mod (`horizon-mod.toml`, `assets/`, `data/`) whose machines run on Farmer's Delight's code. Release [`oceansdelight-v1.0.2-horizon.3`](https://github.com/lavoide/horizon-ports/releases/tag/oceansdelight-v1.0.2-horizon.3) holds `oceansdelight.hmod`, packed from this folder. Earlier versions are in this folder's history.
