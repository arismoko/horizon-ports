# Armor Statues

Sneak and use an armor stand with an empty hand to pose, style and move it.

A port of [Armor Statues](https://github.com/Fuzss/armorstatues) by Fuzs, under the original's licence (MPL-2.0, in `LICENSE`; see `NOTICE`).

It is being ported to Sunrise. Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
