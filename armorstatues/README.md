# Armor Statues for Horizon

Sneak and use an armor stand with an empty hand to pose, style and move it.

A port of [Armor Statues](https://github.com/Fuzss/armorstatues) 8.0.6 by Fuzs to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MPL-2.0, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod on Horizon's mod API only (no game module, no mixins). Release [`armorstatues-v0.4.0`](https://github.com/lavoide/horizon-ports/releases/tag/armorstatues-v0.4.0) holds `armorstatues.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
