# Radiant Gear for Horizon

Worn trinkets that glow give dynamic light.

A port of [Radiant Gear](https://github.com/illusivesoulworks/radiantgear) 2.1.6 by Illusive Soulworks to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-3.0-or-later, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod. Its code uses Horizon's mod API and engine mixins (listed in `horizon-mod.toml`). Release [`radiantgear-v0.4.1`](https://github.com/lavoide/horizon-ports/releases/tag/radiantgear-v0.4.1) holds `radiantgear.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
