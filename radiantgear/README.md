# Radiant Gear

Worn trinkets that glow give dynamic light.

A port of [Radiant Gear](https://github.com/illusivesoulworks/radiantgear) by Illusive Soulworks, under the original's licence (LGPL-3.0-or-later, in `LICENSE`; see `NOTICE`).

It has not been ported to Sunrise yet. Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
