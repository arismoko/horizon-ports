# Panda's Falling Tree's for Horizon

Trees fall when their base is cut.

A port of [Panda's Falling Tree's](https://github.com/PandaMods-Dev/Pandas-Falling-Trees) 0.13.2 by The Panda Oliver to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (GPL-3.0-only, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod on Horizon's mod API only (no game module, no mixins). Release [`fallingtrees-v0.4.0`](https://github.com/lavoide/horizon-ports/releases/tag/fallingtrees-v0.4.0) holds `fallingtrees.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
