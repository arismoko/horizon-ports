# Clutter for Horizon

Furniture you can sit on, candles and chandeliers, lamps, curtains that open, cupboards, copper, silver and onyx.

A port of [Clutter](https://github.com/EmilsGithub/Clutter-Mod-Repository) 1.20-0.6.2 (Fabric 1.20.1) by EmilSG to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod on Horizon's mod API only (no game module, no mixins). Release [`clutter-v0.2.1`](https://github.com/lavoide/horizon-ports/releases/tag/clutter-v0.2.1) holds `clutter.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
