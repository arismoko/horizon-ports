# Clutter

Furniture you can sit on, candles and chandeliers, lamps, curtains that open, cupboards, copper, silver and onyx.

A port of [Clutter](https://github.com/EmilsGithub/Clutter-Mod-Repository) by EmilSG, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

It has not been ported to Sunrise yet. Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
