# YUNG's Bridges for Horizon

Bridges over rivers.

A port of [YUNG's Bridges](https://github.com/yungnickyoung/YUNGs-Bridges) 4.0.3 by YUNGNICKYOUNG to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-3.0-only, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod. Its code uses Horizon's mod API and engine mixins (listed in `horizon-mod.toml`). Release [`yungsbridges-v0.4.1`](https://github.com/lavoide/horizon-ports/releases/tag/yungsbridges-v0.4.1) holds `yungsbridges.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
