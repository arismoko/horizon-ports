# Spelunkery

Ores in granite, andesite, diorite and tuff, rough gems and raw nuggets, cave mushrooms, rock salt, glowsticks, rope ladders and mining tools.

A port of [Spelunkery](https://github.com/AstralOrdana/Spelunkery) by Ordana and Keybounce, under the original's licence (LGPL-3.0-only, in `LICENSE`; see `NOTICE`).

It has not been ported to Sunrise yet. Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
