# Crate Delight for Horizon

Storage crates and bags for crops, fish and other foods: nine of an item in one block.

A port of [Crate Delight](https://github.com/axperty/cratedelight) 26.07.01-1.20-fabric by Axperty to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

This folder is the package: a content mod (`horizon-mod.toml`, `assets/`, `data/`) whose machines run on Farmer's Delight's code. Release [`cratedelight-v26.07.01-horizon.3`](https://github.com/lavoide/horizon-ports/releases/tag/cratedelight-v26.07.01-horizon.3) holds `cratedelight.hmod`, packed from this folder. Earlier versions are in this folder's history.
