# BetterThanMending for Horizon

Sneak-use to repair mending gear with experience.

A port of [BetterThanMending](https://github.com/legobmw99/BetterThanMending/tree/fabric) 1.3.0 by legobmw99 to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (GPL-3.0-only, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod on Horizon's mod API only (no game module, no mixins). Release [`betterthanmending-v0.4.0`](https://github.com/lavoide/horizon-ports/releases/tag/betterthanmending-v0.4.0) holds `betterthanmending.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
