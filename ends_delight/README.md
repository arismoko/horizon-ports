# End's Delight for Horizon

End foods for Farmer's Delight: shulker, dragon and chorus dishes, the End Stove, knives (needs Farmer's Delight 0.5 or later).

A port of [End's Delight](https://github.com/FoggyHillside/End-s-Delight) refabricated-1.20.1-2.5 by FoggyHillside to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

This folder is the package: a content mod (`horizon-mod.toml`, `assets/`, `data/`) whose machines run on Farmer's Delight's code. Release [`ends_delight-v2.5-horizon.4`](https://github.com/lavoide/horizon-ports/releases/tag/ends_delight-v2.5-horizon.4) holds `ends_delight.hmod`, packed from this folder. Earlier versions are in this folder's history.
