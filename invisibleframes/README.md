# Invisible Frames for Horizon

Sneak-use an item frame to make it invisible.

A port of [Invisible Frames](https://github.com/Roundaround/mc-fabric-invisible-frames) 1.1.0 by Roundaround to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod. Its code uses Horizon's mod API and engine mixins (listed in `horizon-mod.toml`). Release [`invisibleframes-v0.4.0`](https://github.com/lavoide/horizon-ports/releases/tag/invisibleframes-v0.4.0) holds `invisibleframes.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
