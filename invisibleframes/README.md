# Invisible Frames for Sunrise

Sneak and use an item frame that holds an item to make the frame invisible: only the item stays in view. Do it again to show the frame.

- Works on item frames and glow item frames.
- A frame that loses its item becomes visible again, so an empty frame is never lost from sight.
- Fixed frames (made with commands) are left alone.

A port of [Invisible Frames](https://github.com/Roundaround/mc-fabric-invisible-frames) 2.0.1 by Roundaround to [Sunrise](https://playsunrise.net) (Minecraft Java 26.3), written in Rust on Sunrise's mod API, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).
