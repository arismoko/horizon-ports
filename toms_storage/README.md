# Tom's Simple Storage for Horizon

Join chests into one network and reach it all from a storage or crafting terminal.

A port of [Tom's Simple Storage](https://github.com/tom5454/Toms-Storage) 1.7.1 (Fabric 1.20.1) by tom5454 to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod on Horizon's mod API only (no game module, no mixins). Release [`toms_storage-v0.3.0`](https://github.com/lavoide/horizon-ports/releases/tag/toms_storage-v0.3.0) holds `toms_storage.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
