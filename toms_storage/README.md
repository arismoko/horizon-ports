# Tom's Simple Storage

Join chests into one network and reach it all from a storage terminal.

A port of [Tom's Simple Storage](https://github.com/tom5454/Toms-Storage) by tom5454, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

It has not been ported to Sunrise yet. Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
