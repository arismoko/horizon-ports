# Mythic Upgrades

Eight gems and necoium with their ores and crystal geodes, and armour sets and tools that each have their own effect.

A port of [Mythic Upgrades](https://github.com/TriQue06/mythic-upgrades-multiloader/tree/1.20.1) by TriQue, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

It has not been ported to Sunrise yet. Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
