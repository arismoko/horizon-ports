# Nether's Delight Refabricated for Horizon

Nether foods for Farmer's Delight: stuffed hoglin, Blackstone Stove and furnaces, propelplants, machetes (needs Farmer's Delight 0.5 or later).

A port of Nether's Delight Refabricated to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-2.1-only, in `LICENSE`; see `NOTICE`).

This folder is the package: a content mod (`horizon-mod.toml`, `assets/`, `data/`) whose machines run on Farmer's Delight's code. Release [`nethersdelight-v4.1.1-horizon.3`](https://github.com/lavoide/horizon-ports/releases/tag/nethersdelight-v4.1.1-horizon.3) holds `nethersdelight.hmod`, packed from this folder. Earlier versions are in this folder's history.
