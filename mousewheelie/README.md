# Mouse Wheelie

Scroll items between inventories, sort with the middle button, pick the right tool.

A port of [Mouse Wheelie](https://github.com/Siphalor/mouse-wheelie) by Siphalor, under the original's licence (Apache-2.0, in `LICENSE`; see `NOTICE`).

It has not been ported to Sunrise yet. Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
