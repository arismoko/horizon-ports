# Tokimi's Toolshed

Hammers, excavators, scythes, copper buckets and other tools.

A port of [Tokimi's Toolshed](https://github.com/CozyCord/TokimisToolshed) by Tokimi, CozyStudios, under the original's licence (CC0-1.0, in `LICENSE`; see `NOTICE`).

It has not been ported to Sunrise yet. Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
