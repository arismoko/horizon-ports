# Crafting Pad

A portable crafting table.

A port of [Crafting Pad](https://github.com/StrikerRockers-Mods/CraftingPad) by StrikerRocker, Giselbaer, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

Its port to Sunrise is blocked on mod-API gaps: [#4592](https://github.com/sunrise-org/sunrise/issues/4592). Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
