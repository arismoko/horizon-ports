# Carry On for Horizon

Sneak and right-click with empty hands to pick up chests and other block entities, or small mobs, and carry them.

A port of [Carry On](https://github.com/Tschipp/CarryOn) 2.1.2.7 (Fabric 1.20.1) by Tschipp, Purplicious_Cow, cy4n to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-3.0-only, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod on Horizon's mod API only (no game module, no mixins). Release [`carryon-v0.3.0`](https://github.com/lavoide/horizon-ports/releases/tag/carryon-v0.3.0) holds `carryon.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
