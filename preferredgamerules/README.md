# Preferred Gamerules for Horizon

New worlds start with your preferred game rules.

A port of [Preferred Gamerules](https://github.com/Estecka/mc-Preferred-Gamerules) 1.1.1+1.19.4 by Estecka to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod on Horizon's mod API only (no game module, no mixins). Release [`preferredgamerules-v0.4.0`](https://github.com/lavoide/horizon-ports/releases/tag/preferredgamerules-v0.4.0) holds `preferredgamerules.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
