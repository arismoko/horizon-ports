# Things for Horizon

Trinkets and gadgets from Things (subset).

A port of [Things](https://github.com/glisco03/things) 0.3.3 by glisco to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod. Its code uses Horizon's mod API and engine mixins (listed in `horizon-mod.toml`). Release [`things-v0.4.0`](https://github.com/lavoide/horizon-ports/releases/tag/things-v0.4.0) holds `things.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
