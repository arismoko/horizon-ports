# Too Cheap!

Anvil repairs never become Too Expensive.

A port of [Too Cheap!](https://github.com/the-sh4d0w/too-cheap) by Sh4d0w, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

Its port to Sunrise is blocked on mod-API gaps: [#5375](https://github.com/sunrise-org/sunrise/issues/5375). Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
