# Pumpkins Accelerated for Horizon

Pumpkins Accelerated: carved pumpkin faces and more.

A port of [Minecraft Accelerated](https://github.com/Cookieglue/PumpkinsAccelerated) 1.0.0 by Mari to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (CC0-1.0, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod. Its code uses Horizon's mod API and engine mixins (listed in `horizon-mod.toml`). Release [`mcaccel-v0.4.0`](https://github.com/lavoide/horizon-ports/releases/tag/mcaccel-v0.4.0) holds `mcaccel.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
