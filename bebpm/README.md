# BEBPM

Enchanting tables count bookshelves further away.

A port of [BEBPM](https://www.curseforge.com/projects/1462757) by CozyStudios, under the original's licence (CC0-1.0, in `LICENSE`; see `NOTICE`).

Its port to Sunrise is blocked on mod-API gaps: [#5374](https://github.com/sunrise-org/sunrise/issues/5374). Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
