# Universal Graves

Your items wait in a grave where you died.

A port of [Universal Graves](https://github.com/Patbox/UniversalGraves) by Patbox, under the original's licence (LGPL-3.0-only, in `LICENSE`; see `NOTICE`).

It has not been ported to Sunrise yet. Until then this folder holds an earlier port's source, written for an older mod format; it does not build with `cargo sunrise-mod`, and there is no Sunrise release.
