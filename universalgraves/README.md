# Universal Graves for Horizon

Your items wait in a grave where you died.

A port of [Universal Graves](https://github.com/Patbox/UniversalGraves) 3.0.3 by Patbox to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (LGPL-3.0-only, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod. Its code uses Horizon's mod API and engine mixins (listed in `horizon-mod.toml`). Release [`universalgraves-v0.4.3`](https://github.com/lavoide/horizon-ports/releases/tag/universalgraves-v0.4.3) holds `universalgraves.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
