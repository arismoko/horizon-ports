# Expanded Delight for Horizon

Asparagus, sweet potatoes, chili peppers, peanuts, cinnamon, salt, juices, the juicer and the mortar (needs the Farmer's Delight port).

A port of [Expanded Delight](https://github.com/ianm1647/expandeddelight) 0.3.2 by ianm1647 to [Horizon](https://github.com/horizon-rust/horizon) 26.3, under the original's licence (MIT, in `LICENSE`; see `NOTICE`).

This folder is the package source: one native mod on Horizon's mod API only (no game module, no mixins). Release [`expandeddelight-v0.6.0`](https://github.com/lavoide/horizon-ports/releases/tag/expandeddelight-v0.6.0) holds `expandeddelight.hmod`, built from this folder with Horizon's exact-build SDK `dd67b76ff23e28c6d8e21859df600d31572f81a0` (Horizon Mixins `e59da9094f0c2fdda6c627fe9eff22dec6a906f0`). Earlier versions, if any, are in this folder's history.
